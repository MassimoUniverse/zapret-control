# Zapret Control

Графическая оболочка для [zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube) — обхода блокировок на Windows.

Вместо папки с двумя десятками батников и консольного меню — обычное окно: тумблер включения, выбор стратегии, установка службы в автозапуск, редактор списков и диагностика.

<!-- ![Скриншот](screenshot.png) -->

## Возможности

- Включение и выключение обхода одним тумблером
- Выбор стратегии из списка и установка службы с автозапуском
- **FACEIT MODE** — обход для игрового трафика (см. ниже)
- Обновление самого zapret'а в один клик, с сохранением настроек и списков
- Редактирование пользовательских списков прямо в окне
- Диагностика: конфликтующие службы, прокси, WinDivert, Base Filtering Engine
- Быстрые действия: перезапуск службы, открыть папку, открыть лог

## Установка

1. Скачайте `Zapret-Control.zip` из [Releases](../../releases)
2. Распакуйте в любую папку
3. Запустите `Zapret GUI.bat` — права администратора запросит сам

Если zapret не установлен, приложение предложит скачать его автоматически
(GitHub, при недоступности — зеркало SourceForge), распакует одной папкой
и применит настройки.

Если автоскачивание не проходит — возьмите архив `Zapret-Control-with-zapret.zip`,
в нём zapret уже внутри.

Требования: Windows 10/11. Ничего доустанавливать не нужно — используется
PowerShell и WPF, встроенные в систему.

## FACEIT MODE

Обычный обход работает по спискам доменов: смотрит, к какому сайту идёт
соединение, и применяет обход к нему. С играми это не работает — трафик
FACEIT и CS2 идёт по UDP, домена в нём нет, а IP игрового сервера выдаётся
на матч случайно. Опознать такое соединение по списку сайтов невозможно.

FACEIT MODE включает обход на весь диапазон игровых портов (1024–65535)
и на любые IP-адреса. Реализовано через отдельный список `lists/ipset-game.txt`:

- **включён** — в файл пишется `0.0.0.0/0`, игровой фильтр переводится в режим `all`
- **выключен** — заглушка `203.0.113.113/32`, поведение стоковое

На браузер и обычные сайты режим не влияет: игровые правила работают только
на портах выше 1023, а сайты и стриминг идут через 443.

## Безопасность и почему не .exe

Приложение — обычный PowerShell-скрипт. Его можно открыть блокнотом и прочитать
целиком: что он делает, куда обращается, что скачивает. Программа запрашивает
права администратора (иначе нельзя управлять службой), и возможность проверить
исходник здесь важнее удобства «одного файла».

Сборка в `.exe` этот код скрывает, добавляет предупреждение SmartScreen
о неизвестном издателе, а типичная упаковка PowerShell-скрипта в исполняемый
файл ещё и распознаётся антивирусами как подозрительная — тот же приём
используют вредоносные загрузчики. Поэтому распространяется исходник.

Приложение **не отключает Windows Defender**, **не устанавливает сертификаты**
и не меняет системные настройки. Что оно действительно делает:

- создаёт и удаляет службу Windows `zapret` (обычный `winws.exe` из дистрибутива)
- включает TCP timestamps (`netsh interface tcp set global timestamps=enabled`) —
  требование zapret'а для части стратегий
- редактирует списки в папке zapret'а
- скачивает релизы zapret с GitHub / SourceForge
- пишет лог в `utils/zapret-gui.log`

### Ложные срабатывания антивирусов

На файлы **самого zapret'а** антивирусы иногда ругаются: `HackTool`, `RiskTool`
и подобное. Это относится к драйверу WinDivert, которым zapret перехватывает
сетевые пакеты — по принципу работы он делает то же, что снифферы, отсюда
и вердикт. К этой оболочке детект отношения не имеет: в её файлах WinDivert нет,
zapret скачивается отдельно.

## Запуск из исходника

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File ZapretGUI.ps1
```

Полезные ключи для проверки без запуска окна:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File ZapretGUI.ps1 -TestUI
powershell -NoProfile -ExecutionPolicy Bypass -File ZapretGUI.ps1 -RootOverride "C:\путь\к\zapret"
```
